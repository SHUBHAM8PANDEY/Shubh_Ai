The Future of Artificial Intelligence

Engineering questions for building and maintaining systems that use AI models.

How will you evaluate changes?

Keep a versioned set of representative tasks with expected outcomes. Test updates against both quality and latency. For a document assistant, measure whether the cited passage actually supports the answer.

Which actions should require review?

A model can draft a database change or an email without executing it. Require a review step when actions publish information, change records, or spend money. Give the application only the permissions needed for each operation.

Can the system recover?

Model providers can return errors or change behavior between versions. Decide what users see when a request fails, and track how often they need to retry. Preserve enough context to debug errors while limiting the personal data you retain.

Smaller models and specialized workloads

A small classifier can be easier to evaluate and cheaper to run than a general language model. Use the simplest candidate that meets the task’s quality, latency and maintenance targets.

Multimodal input and richer evaluations

As systems combine text, audio and images, evaluate realistic combinations. A transcription component may work in isolation but fail once a microphone changes or screenshots contain small labels.

Building a model-independent interface

Define the messages your application expects, then validate their structure before displaying or using them. Cache inputs only as needed and allow a safe retry when a provider is unavailable.

A worked example for a document assistant

Collect questions that readers actually ask about the documentation. For each question, record a supporting passage, a reasonable answer, and whether the assistant should ask a follow-up. Include questions that refer to outdated instructions and questions for which the documents contain no answer.

Measure retrieval and answer quality independently. If the correct passage is rarely retrieved, improve indexing, chunking, and search before changing the model. If it is retrieved consistently but misquoted, refine answer instructions and use direct passage links reviewers can open.

Plan for updates and retirement

Use a versioned configuration so the team can reproduce an issue and roll back if performance drops. Schedule a repeat of the release evaluation when the model, index, or prompt changes. Keep a manual path for users who need a result while the assistant is unavailable.
