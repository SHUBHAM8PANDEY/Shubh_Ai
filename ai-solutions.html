Learning guide

Artificial intelligence · Machine learning · Deep learning · Generative AI

Artificial intelligence

AI is the broad field of building systems that perform tasks such as recognizing speech, planning routes, or generating text. Some systems use hand-written rules. Others learn from examples. A route planner can search a map for the fastest route using estimated travel times.

Machine learning

Machine learning fits a model using data. A spam classifier can learn from messages labeled spam or legitimate, then estimate a label for a new message. Evaluate it on unseen messages and track both missed spam and legitimate mail caught by mistake.

Deep learning

Deep learning uses neural networks with multiple layers. In an image classifier, early layers can respond to simple patterns such as edges, while later layers combine signals into more task-specific representations. Performance can drop if new images differ from the training data.

Generative AI

Generative models produce new content such as text, images, or audio. A language model typically generates text one token at a time using the context it has received. Fluent output can contain unsupported claims, so check important details against source material.

Text analyzer

Count words and Unicode code points locally. The reading estimate uses 200 words per minute and rounds up. Language models split text into tokens, which can represent whole words, parts of words, or punctuation.

Evaluation notes

Accuracy

Define what counts as a correct result before collecting examples.

Coverage

Check rare categories and scenarios that appear only occasionally.

Latency

Record typical and slow requests to find where users may need feedback.

Reliability

Test incomplete inputs and external-service failures.

Privacy

Limit data collection to what the feature actually needs.

Human review

Make corrections visible and reversible.

Accessibility

Test with keyboard controls and assistive technology.

Maintenance

Revisit benchmarks when data, dependencies or model versions change.
